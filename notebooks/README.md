# notebooks/

Exploración de datos (EDA) y pruebas rápidas. La solución final no depende de notebooks: se ejecuta con
`train.py`, `run_tests.py` y `app.py`.

`01_exploracion_corpus.ipynb` (Hito 2): lee los conteos que genera el pipeline (`experiments/hito2/`) y muestra tamaños,
desbalance, duplicados, idioma, particiones y posibles atajos. Las celdas de interpretación están vacías para que las
complete el equipo cuando exista la corrida con datos reales.
